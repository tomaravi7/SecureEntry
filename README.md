# SecureEntry

Secure Entry is a Flutter application designed to streamline and secure the entry management system for residential communities. This app allows residents to notify guards about expected guests, packages, and other relevant notifications. It also includes features for different user roles such as admin, resident, and guard, ensuring a tailored experience for each type of user.

Features
1. User Authentication: Secure login and registration using Supabase.
2. Role-Based Access Control: Different interfaces and functionalities for admin, resident, and guard roles.
3. Real-Time Notifications: Residents can notify guards about expected guests, packages, complaints, and emergencies.
4. Time Selection: Users can specify expected arrival times for guests or packages.

# Installation

1. Clone the repository:
   ```bash
     git clone https://github.com/your-username/secure-entry.git
     cd secure-entry
   ```
2. Install dependencies:
   ```bash
     flutter pub get
   ```
3. Set up Supabase: 
   Create a project on Supabase.
   Configure your Supabase URL and public API key in your Flutter project.
4. Run the app:
   ```bash
     flutter run
   ```
